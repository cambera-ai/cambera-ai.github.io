# cambera-ai.github.io

Source of **https://cambera-ai.github.io/** — Cambera's public website.

> Our mission is to raise the productivity and efficiency of the entire construction
> industry, worldwide.

Two languages, two URLs, no JavaScript: `/` is English, `/pl/` is Polish. Static pages,
no build step — one HTML file per language with inline CSS, published with GitHub Pages.

Fonts (Space Grotesk, JetBrains Mono) are self-hosted, so loading the site sends no
request to a third party; licences and the subsetting recipe are in `assets/fonts/`.

Want early access? Use the form on the site.
